# MCKL Transfer

**ไฟล์ของคุณ อุปกรณ์ของคุณ พื้นที่ที่คุณควบคุมเอง**

แชร์ไฟล์ผ่านเบราว์เซอร์ด้วยเซิร์ฟเวอร์ของคุณ เหมาะกับการใช้งานส่วนตัว ครอบครัว และทีมขนาดเล็ก

**0.5.0 · Apache-2.0 · ไม่ต้องติดตั้งแอปฝั่งไคลเอนต์ · ไม่มี npm dependency ขณะรัน**

ย้ายวิดีโอเข้าเครื่องคอมพิวเตอร์ ส่งเอกสารระหว่างอุปกรณ์ หรือสร้างกล่องรับไฟล์ให้ทีม MCKL Transfer เปลี่ยนคอมพิวเตอร์หนึ่งเครื่องเป็นจุดแชร์ไฟล์ อุปกรณ์อื่นเปิดเบราว์เซอร์แล้วเชื่อมต่อได้ โดยไม่ต้องมีบัญชีคลาวด์ของ MCKL

## ฟีเจอร์ที่ช่วยให้ใช้งานได้ทุกวัน

| ฟีเจอร์ | ประโยชน์ |
|---|---|
| อัปโหลดต่อได้ | หยุดชั่วคราว ลองใหม่ ตรวจ SHA-256 และค้นผลการอัปโหลดเดิมได้แม้คำตอบสุดท้ายขาดหาย |
| เลือกขอบเขตการแชร์ | พื้นที่ส่วนกลาง inbox ตามผู้รับ และห้องที่กำหนดสมาชิก |
| เชิญด้วย QR | ลิงก์ใช้ครั้งเดียว มีวันหมดอายุ และเลือกให้โฮสต์อนุมัติอุปกรณ์ก่อนได้ |
| โฟลเดอร์และดาวน์โหลดเป็นชุด | เก็บพาธสัมพัทธ์ และดาวน์โหลดไฟล์ที่เลือกเป็น `.tar` แบบสตรีม |
| เครื่องมือใช้งานประจำ | ค้นหา แชต ประวัติการส่ง และตั้งเวลาให้ไฟล์หมดอายุ |
| การส่งตรงแบบทดลอง | เซสชัน WebRTC ที่ผู้รับยอมรับ พร้อมแสดงเส้นทาง direct/relay |
| ควบคุมทรัพยากร | โควตาต่ออุปกรณ์ จำกัดจำนวนไฟล์และดาวน์โหลด พร้อม lease ฝั่งเซิร์ฟเวอร์ระหว่างแท็บ |

## เริ่มใช้งาน

ติดตั้ง Node.js **24.x ตั้งแต่ 24.22.2** หรือ **26.x ตั้งแต่ 26.13.0** บนเครื่องโฮสต์

```sh
git clone https://github.com/hieunguyenak92/MCKLTransfer.git
cd MCKLTransfer
npm start
```

ไม่ต้องรัน `npm install` นอกจากนี้ยังดาวน์โหลดซอร์สจาก [Releases](https://github.com/hieunguyenak92/MCKLTransfer/releases) เพื่อเริ่มใช้งานได้

1. เปิด URL ของ LAN ที่แสดงในเทอร์มินัลจากเบราว์เซอร์บนอีกอุปกรณ์
2. ใส่ชื่ออุปกรณ์และรหัสเข้าถึงหกหลัก
3. เลือกปลายทาง แล้วส่งไฟล์หรือโฟลเดอร์

**รหัสผู้ดูแลแยกต่างหาก** ใช้เฉพาะผู้ดูแลโฮสต์ แผงผู้ดูแลใช้อนุมัติหรือเพิกถอนอุปกรณ์ สร้างคำเชิญ และจัดการห้องได้

HTTP ซึ่งเป็นค่าเริ่มต้นไม่เข้ารหัสการเชื่อมต่อ จึงควรใช้เฉพาะ LAN ที่ควบคุมและเชื่อถือได้ สำหรับการเชื่อมต่ออื่นให้ตั้งค่า HTTPS ที่อุปกรณ์เชื่อถือ หรือใช้ Tailscale/WireGuard ที่จำกัดสิทธิ์ อย่าเปิดพอร์ต HTTP นี้สู่อินเทอร์เน็ตโดยตรง

## พื้นที่ส่วนกลางหรือ inbox ส่วนตัว

- **พื้นที่ส่วนกลาง:** แชร์ไฟล์และแชตกับสมาชิกที่อนุมัติแล้ว
- **inbox ส่วนตัว:** เข้าถึงได้เฉพาะผู้ส่ง ผู้รับที่เลือก และผู้ดูแลโฮสต์ที่เชื่อถือ
- **ห้อง:** ผู้ดูแลเลือกสมาชิก เซิร์ฟเวอร์ตรวจสิทธิ์ทั้งรายการไฟล์ ดาวน์โหลด และอีเวนต์

ปุ่มเชิญสร้างลิงก์และ QR ที่ใช้ได้สิบนาที คำเชิญใช้ได้ครั้งเดียวและไม่คงอยู่หลังรีสตาร์ตเซิร์ฟเวอร์ หากต้องการให้โฮสต์อนุมัติอุปกรณ์ใหม่ก่อน:

```sh
REQUIRE_APPROVAL=1 npm start
```

เมื่ออัปโหลดหลุด ให้เลือกไฟล์เดิมอีกครั้งเพื่อส่งต่อ โดยต้องใช้คุกกี้อุปกรณ์เดิมและรายการอัปโหลดยังไม่หมดอายุ lease บนเซิร์ฟเวอร์ป้องกันหลายแท็บแก้ไขการอัปโหลดเดียวกันพร้อมกัน

สถานะ “โฮสต์รับแล้ว” ต่างจาก “ผู้รับบันทึกแล้ว” เบราว์เซอร์ที่รองรับการบันทึกพร้อมตรวจสอบจะส่งใบรับหลังเขียนไฟล์และตรวจ SHA-256 เสร็จ

## ส่งตรงผ่าน WebRTC — ฟีเจอร์ทดลอง

เมื่อทั้งสองอุปกรณ์ออนไลน์ สามารถเลือกเซสชันที่ไม่เก็บไฟล์ไว้บนโฮสต์ได้

1. เลือกผู้รับและไฟล์ที่จะส่งตรง
2. ผู้รับยอมรับและเลือกตำแหน่งบันทึก
3. **เปรียบเทียบรหัสบนทั้งสองอุปกรณ์ผ่านช่องทางอื่นที่เชื่อถือ แล้วกดยืนยันทั้งสองฝั่ง**
4. ฝั่งรับเขียนข้อมูลเป็นบล็อกเล็ก ๆ และตรวจขนาดกับ SHA-256

ต้องใช้ HTTPS หรือ localhost ฝั่งรับต้องรองรับ `showSaveFilePicker` โดยเน้น Chromium บนเดสก์ท็อป ไม่รวมไฟล์ทั้งก้อนเป็น Blob ไว้ใน RAM หากอุปกรณ์ไม่รองรับหรือเชื่อมต่อไม่สำเร็จ สามารถเลือกส่งผ่านโฮสต์อย่างชัดเจนได้ ไม่มีการเปลี่ยนที่เก็บไฟล์และขอบเขตความเป็นส่วนตัวโดยซ่อนไว้ใน fallback อัตโนมัติ

ค่าเริ่มต้นไม่ตั้งค่า STUN/TURN ภายนอก หากจำเป็นให้ระบุเซิร์ฟเวอร์ที่ดูแลเองผ่าน `ICE_SERVERS` เส้นทาง relay หมายถึงการส่งผ่าน TURN ไม่รับประกันว่าจะเชื่อมต่อตรงได้ทุกเครือข่าย ดู[คู่มือตั้งค่า](../CONFIGURATION.md)

## ขอบเขตความเป็นส่วนตัวที่ชัดเจน

โฮสต์อ่านไฟล์และแชตที่ผ่านการจัดเก็บบนโฮสต์ได้ inbox ส่วนตัวเป็นการควบคุมสิทธิ์ ไม่ใช่ E2EE ที่ป้องกันโฮสต์ การเข้ารหัสเซสชันตรงและการเทียบรหัสก็ไม่ป้องกัน JavaScript อันตรายที่โฮสต์ซึ่งถูกโจมตีส่งให้เบราว์เซอร์

เปิดหน้าเว็บไว้ระหว่างส่ง โดยเฉพาะบนมือถือ PWA ไม่รับประกันการส่งเบื้องหลังหรือขณะ iPhone ล็อกหน้าจอ และไม่มีฟีเจอร์ควบคุมเดสก์ท็อประยะไกล

## การดูแลและอัปเกรด

- `SHARE_DIR` เก็บข้อมูลส่วนตัว รายละเอียดโควตา จำนวนไฟล์ อายุไฟล์ HTTPS และ ICE อยู่ใน[คู่มือตั้งค่า](../CONFIGURATION.md) โปรแกรมไม่โหลด `.env` อัตโนมัติ
- หยุดเซิร์ฟเวอร์ก่อนอัปเกรด แล้วสำรองไดเรกทอรีข้อมูลทั้งหมดอย่างปลอดภัย ล็อกจะปฏิเสธโฮสต์โปรเซสที่สองซึ่งใช้ไดเรกทอรีเดียวกัน
- การหยุดและเริ่มตามปกติจะเก็บเซสชันไว้ หลังหยุดผิดปกติต้องจับคู่ใหม่เพื่อความปลอดภัย ผู้ดูแลเป็นผู้จัดการการกู้คืนสิทธิ์เจ้าของเดิม
- การหมดอายุไม่ใช่การลบข้อมูลอย่างปลอดภัยและไม่ลบสำเนาในแบ็กอัป ไม่รับประกันพฤติกรรมเดียวกันบนไดรฟ์เครือข่ายหรือเมื่อไฟดับ

ความเร็วขึ้นกับเครือข่าย ดิสก์ การคำนวณแฮช และอุปกรณ์ เงื่อนไขการวัดและขอบเขตการตรวจสอบอยู่ใน[บันทึกการตรวจสอบ](../VALIDATION.md) ตัวเลข loopback ไม่ใช่คำรับประกันความเร็ว LAN
