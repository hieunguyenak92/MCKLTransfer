# MCKL Transfer

**你的文件，你的设备，你自己的共享空间。**

面向个人、家庭和小团队的自托管文件共享，打开浏览器即可使用。

[下载最新版本](https://github.com/hieunguyenak92/MCKLTransfer/releases/latest) · [配置指南](../CONFIGURATION.md) · [点亮 Star](https://github.com/hieunguyenak92/MCKLTransfer)

**0.5.0 · Apache-2.0 · 客户端免安装 · 无 npm 运行时依赖**

</div>

把视频传到电脑，在设备之间发送资料，或为团队建立一个小型收件箱。MCKL Transfer 让你的一台电脑成为共享中心，其他设备通过浏览器连接。无需注册 MCKL 云账号。

## 为日常传输准备的功能

| 功能 | 带来的便利 |
|---|---|
| 可恢复上传 | 暂停、重试、SHA-256 校验；完成响应丢失后仍能查询同一次上传的结果 |
| 按需选择共享范围 | 公共空间、指定收件人的私有 inbox、限定成员的房间 |
| 扫码邀请 | 有效期内仅可使用一次的邀请，可选主机审批 |
| 文件夹与批量下载 | 保留相对路径，将所选文件以流式 `.tar` 下载 |
| 实用管理工具 | 搜索、聊天、传输历史和文件自动过期 |
| 实验性直传 | 收件人明确接受的 WebRTC 会话，显示 direct/relay 路径 |
| 资源控制 | 每设备配额、文件数量与下载限制、服务器端跨标签页上传租约 |

## 快速开始

主机安装 Node.js **24.x（24.22.2 起）**或 **26.x（26.13.0 起）**。

```sh
git clone https://github.com/hieunguyenak92/MCKLTransfer.git
cd MCKLTransfer
npm start
```

无需 `npm install`。也可以从 [Releases](https://github.com/hieunguyenak92/MCKLTransfer/releases) 下载源码后运行。

1. 在另一台设备的浏览器中打开终端显示的局域网 URL。
2. 输入设备名称和六位访问码。
3. 选择共享目标，发送文件或文件夹。

**独立管理员码**只应由主机管理员使用。管理员可以批准或撤销设备、生成邀请并管理房间。

默认 HTTP 不加密连接，只适用于受控且可信的局域网。其他场景请配置受信任的 HTTPS，或限制访问的 Tailscale/WireGuard 网络。不要将此 HTTP 端口直接暴露到互联网。

## 公共空间，也可以只发给指定的人

- **公共空间：**已批准的成员共享文件和聊天。
- **私有 inbox：**仅发送者、指定收件人和受信任的主机管理员可访问。
- **房间：**管理员选择成员；服务器在列表、下载和事件中执行权限检查。

邀请按钮生成有效期为十分钟的链接和二维码。每份邀请仅可使用一次，服务器重启后失效。如需每台新设备先经主机批准：

```sh
REQUIRE_APPROVAL=1 npm start
```

上传中断后，重新选择同一文件即可恢复；需要保留相同的设备 Cookie，且上传尚未过期。服务器租约防止多个标签页同时修改同一次上传。

“主机已接收”和“收件人已保存”是不同状态。支持校验保存的浏览器会在写入文件并核对 SHA-256 后发送回执。

## WebRTC 直传——实验性功能

两端均在线时，可以选择不将文件保存到主机的直接传输会话。

1. 选择收件人和要直接发送的文件。
2. 收件人接受传输并选择保存位置。
3. **通过另一种可信方式比较两端显示的确认码，并在两端分别确认。**
4. 接收端分块写入文件，校验大小和 SHA-256。

需要 HTTPS 或 localhost。接收端必须支持 `showSaveFilePicker`，主要面向桌面 Chromium 浏览器。不会把整个文件拼成 Blob 留在内存中。设备不支持或连接失败时，可明确选择通过主机传输；不会悄悄改变文件存储位置和隐私边界。

默认不配置任何外部 STUN/TURN。需要时可通过 `ICE_SERVERS` 指定自行管理的服务器。relay 表示流量经 TURN 中继，不保证所有网络都能建立直接连接。详见[配置指南](../CONFIGURATION.md)。

## 清晰的信任边界

主机可以读取通过它保存的文件和聊天。私有 inbox 提供访问控制，并非针对主机的端到端加密。直接会话的加密和确认码比较，也不能防御被攻陷的主机向浏览器提供恶意 JavaScript。

传输期间请保持页面打开，尤其是在手机上。PWA 不保证后台传输，也不保证 iPhone 锁屏后继续传输。项目不包含远程桌面控制。

## 运维与升级

- `SHARE_DIR` 保存私有数据。容量、文件数量、有效期、HTTPS 与 ICE 参数见[配置指南](../CONFIGURATION.md)。程序不会自动加载 `.env`。
- 升级前停止服务器，并安全备份整个数据目录。同一目录的第二个主机进程会被锁拒绝启动。
- 正常停止并重启会保留设备会话。异常终止后采用安全优先策略，需要重新配对；原有文件所有权的恢复由管理员处理。
- 文件过期不等于安全擦除，也不会删除备份中的副本。不统一保证网络盘行为或断电恢复能力。

速度取决于网络、磁盘、哈希计算和设备性能。[验证记录](../VALIDATION.md)说明测量条件和验证范围，不将 loopback 数据当作局域网速度承诺。
