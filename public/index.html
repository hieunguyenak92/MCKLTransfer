Thả file để chia sẻ

File được lưu trên máy chủ. Những người đã kết nối có thể tải file và đọc chat chung.

Địa chỉ để mở trên thiết bị khác

File trên hub có thể được chủ máy đọc. Inbox riêng chỉ hiển thị cho người gửi, người nhận và quản trị viên.

Phiên truyền trực tiếp

Chọn người nhận, so sánh mã trên cả hai thiết bị rồi xác nhận. Nhận trực tiếp cần HTTPS/localhost và trình duyệt hỗ trợ ghi file theo luồng. Có thể chủ động chuyển sang hub.
